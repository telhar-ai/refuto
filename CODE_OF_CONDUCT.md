# Código de conducta

Este proyecto adopta el **Contributor Covenant, versión 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

En resumen: se discuten ideas y evidencia, no personas. Se esperan respeto, crítica
concreta y disposición a que te refuten, que es el oficio de este proyecto.

Para reportar una conducta inaceptable, abre un aviso privado al mantenedor mediante
«Report a vulnerability / Security advisories» del repositorio, o escribe a la dirección
que figure en el perfil público del mantenedor. Los reportes se tratan con confidencialidad.
